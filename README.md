# Calculator Project

A simple, interactive web-based calculator built using HTML, CSS, and JavaScript.

## Features
- **Basic Arithmetic Operations:** Perform addition, subtraction, multiplication, and division.
- **Clear & Delete:** Easily clear the entire display or delete the last entered character.
- **Decimal Support:** Perform calculations with floating-point numbers.
- **Responsive Design:** Clean and user-friendly interface.

## Technologies Used
- **HTML5:** For the structure and layout of the calculator.
- **CSS3:** For styling, colors, and button layouts.
- **JavaScript:** For the calculator's logic and interactivity.

## How to Run
1. Open the project folder.
2. Double-click on `index.html` to open it in your default web browser.
3. Start calculating!

## File Structure
- `index.html` - The main HTML file containing the calculator's structure.
- `style.css` - The CSS file containing all the styling rules.
- `script.js` - The JavaScript file containing the calculator's operational logic.
