# Aurora Gallery

A beautiful, responsive image gallery built with HTML, CSS, and JavaScript.

## Features
- **Responsive Grid:** The gallery adapts to different screen sizes beautifully.
- **Lightbox Overlay:** Click on any image to view it in full screen with a sleek lightbox.
- **Filtering System:** Filter images by their category (Nature, Urban, Abstract).
- **Keyboard Navigation:** Navigate through the gallery using keyboard arrows.
- **Touch Support:** Swipe left and right on mobile devices to navigate between images.

## Setup
1. Clone the repository.
2. Open `index.html` in your web browser. No build steps required!

## Project Structure
- `index.html` - The main structure of the gallery.
- `style.css` - All styling, grid layouts, and animations.
- `script.js` - Logic for rendering images, filtering, and the lightbox.

## Technologies Used
- HTML5
- Vanilla CSS3
- Vanilla JavaScript
